        Pourquoi deux niveaux de preuve ?
        
Signet seul : le dépôt figure dans Notion, sans consultation de son README. GitHub vérifié : les métadonnées et un extrait du README ont été récupérés à la date indiquée. Dans les deux cas, le score lexical ne prouve pas l'adéquation à ton besoin.

        
L'avis IA facultatif n'est transmis qu'après aperçu et confirmation. Les clés restent côté Python. L'import et la modification des fiches Notion restent désactivés.
