CONFIGURATION IA

Vos modèles, à la carte.

Configurez vos fournisseurs et leurs modèles. Les clés restent dans votre fichier .env privé ; elles ne sont jamais renvoyées au navigateur.

Fournisseur et modèle

La recherche du catalogue V3 reste locale. Ces paramètres sont destinés aux analyses IA facultatives et à l'import futur.


          
La vérification utilise les API de contrôle des fournisseurs, sans demander de génération. Aucun import Notion n'est disponible ici.

        

        
Confidentialité
Les clés sont sauvegardées dans le fichier .env du dossier de données local. Elles y sont stockées en clair : protégez l'accès Windows à ce dossier. L'interface ne transmet ces clés qu'au fournisseur sélectionné lors de l'utilisation explicite de ses API.
